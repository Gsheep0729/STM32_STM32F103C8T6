# STM32F103C8T6 实验与笔记

跟随视频课程推进的 STM32F103C8T6 学习仓库。Keil MDK + 标准外设库 V3.5.0，一个实验单元一个顶层目录（单工程型，或容器型 + 功能子目录），代码与笔记同仓提交。

工程规则与实验大纲见本地 `CLAUDE.md`（**不入库**，仅本机保留；如需可取回历史提交中的版本）。

## 目录结构

```
00stm32介绍和环境配置/   纯笔记 + 图片；含 `00stm32介绍和环境配置.md`（第 0 章笔记）与 `STM32入门教程.md`（全课程成书）+ `STM32入门教程.assets/`
01工程模板/              单工程型：Keil 工程模板 + 01新建工程.md
02GPIO/                  容器型：章节笔记 + 图片 + 5 个功能子目录（每个子目录一个完整工程）
README.md                本文件
CLAUDE.md                项目规则（本地保留，**不入库**）
```

每个工程目录内部：`User/`（main.c 等）、`Start/`（启动文件与 `stm32f10x.h`）、`lib/`（标准库外设源码）、`System/`（Delay 等工具）、`批处理中间文件脚本/keilkill.bat`。单工程型在顶层目录，容器型在每个功能子目录内，两者结构完全一致。

构建产物（`Objects/`、`Listings/`、`DebugConfig/`、`*.o` 等）不入库，见 `.gitignore`。
